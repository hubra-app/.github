**Hubra is club management software for Swiss clubs.** Members, QR bills,
events, polls and groups live in one place, and each club turns on the
modules and plugins it needs. We run it for you at
[hubra.club](https://hubra.club), or you host it yourself with Docker Compose
or k3s.

### Repositories

| Repository | What it is |
| --- | --- |
| [hubra](https://github.com/hubra-app/hubra) | The platform: backend, club app, manager portal and sign-in |
| [hubra-plugins](https://github.com/hubra-app/hubra-plugins) | The official plugin marketplace, signed, at [plugins.hubra.club](https://plugins.hubra.club) |
| [hubra.club](https://github.com/hubra-app/hubra.club) | The website (German and English) |
| [hubra-plugin-bank-import](https://github.com/hubra-app/hubra-plugin-bank-import) | Import bank files (camt.053, camt.054, MT940, CSV) and match payments to invoices |
| [hubra-plugin-imap-inbox](https://github.com/hubra-app/hubra-plugin-imap-inbox) | Read club mailboxes hosted anywhere inside Hubra |
| [hubra-plugin-budgets](https://github.com/hubra-app/hubra-plugin-budgets) | A yearly budget per category, compared with what was booked |
| [hubra-plugin-keys](https://github.com/hubra-app/hubra-plugin-keys) | Who holds which key, card or fob, with a handover log |
| [hubra-plugin-guides](https://github.com/hubra-app/hubra-plugin-guides) | A usage guide per machine or tool, shown on the inventory item |
| [hubra-plugin-discord](https://github.com/hubra-app/hubra-plugin-discord) | Announce events, posts and polls on Discord |
